All code cases: case rate by neighborhood

    Sources and counting

    Sources: city code violation records, neighborhood boundaries and parcels. Based on when violation records were listed in city data (Central Time), not when properties were inspected.

    For this edition, of 1,424 cases, 922 mapped to neighborhoods; 487 had no boundary match and 15 lacked usable coordinates. These 502 are excluded from neighborhood comparisons. Each case counts once per neighborhood overall. Each case counts once in the total, even if it includes several violation types. Use the filters to see cases involving a particular type.

    Neighborhoods with more properties have more places where violations can be recorded. Comparing cases per 1,000 properties helps account for differences in neighborhood size.

    Property counts use the number of city parcels, not homes or apartment complexes. Neither counts nor rates measure severity or safety. These records do not consistently describe the specific problem behind each violation.

    Each neighborhood’s property count includes parcels that extend into it. Touching a boundary alone does not count. In this edition, 1.97% of properties used in rate comparisons count in more than one neighborhood because their parcels extend into multiple neighborhoods.

    Rates are available for 317 neighborhoods. Rates for Madero, Old Weatherford Road and Walsh HOA are pending checks for overlapping or unidentified parcel records. Case counts are included.
