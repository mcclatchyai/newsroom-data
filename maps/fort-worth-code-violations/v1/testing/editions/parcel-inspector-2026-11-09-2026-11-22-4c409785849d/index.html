Sources and counting

The city listed 1,416 code violation records for Nov 9 – 22, 2026. The records included 1,201 different numbered street addresses. 7 records listed a street without a house number.

We use the city’s “violation created date” to count records for the two weeks shown on the map. We checked the data on Nov 23, 2026. Records can appear online after their listed creation date.

900 records mapped to 140 neighborhoods, 500 fell outside all neighborhood boundaries on the city’s map, and 16 lacked usable coordinates.

We count each violation ID once per neighborhood during the two weeks if its mapped location falls inside the boundary. A record in overlapping neighborhoods counts once in each and once in the citywide total.

For each neighborhood, we divide the number of code violation records by the number of counted properties and multiply by 1,000. This accounts for differences in neighborhood size. We include all property types, including homes, businesses and vacant lots. The property count stays the same when you filter by violation type.

A property counts once in every neighborhood that contains at least 40% of its land. For example, a property split 45% and 55% between two neighborhoods counts in both. Adding neighborhood property counts can count the same property more than once. If a county line splits one lot into two parcel records, we count the lot once.

We generally count each city tax parcel as one property, even if its description names two platted lots. Separate parcel IDs with the same outline count separately unless records show they represent the same property.

We count a documented condominium or apartment complex as one property. We use plats, appraisal records and city records to identify the parcels and shared land that make up the development, then apply the 40% test to the whole footprint. We count separately documented developments individually, even when they share a name.

When land records show that separately assessed homes together own an entire shared lot, we count each home on its own footprint. The shared lot adds no extra property. For example, six homes that each own one-sixth of a shared lot count as six properties.

We checked the property counts on Nov 24, 2026. Rates are available for 309 of the 316 neighborhoods on the city’s map. Texas and Pacific Lofts had zero qualifying properties and 0 mapped violation records, so it has no rate. The property count is still under review in 6 neighborhoods. We show the violation records for those neighborhoods. The overall ranking stays on hold while any neighborhood with records lacks a usable property count.

One additional violation record can change the rate substantially in a neighborhood with few properties. The city marked 890 records open and 526 closed when we checked. Those labels do not tell us whether an inspector confirmed a violation or why a record closed. These figures measure recorded code enforcement activity. Counts and rates do not measure severity or safety.
