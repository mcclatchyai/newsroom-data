# Newsroom Data

Static public data files for newsroom maps and story embeds.

## Datasets

- `maps/compasskc-demolitions/v1/prod/` - Canonical public data for Kansas City CompassKC demolition permit maps.
- `maps/compasskc-demolitions/v1/testing/` - Validation copy used before promoting refreshed data to production.
- `compasskc-demolitions/` - Temporary transition mirror for older preview code; do not use for new embeds.

## CompassKC Demolitions

- `maps/compasskc-demolitions/v1/prod/manifest.json` lists the current files, available years, public schema, cache metadata, and entrypoints.
- `maps/compasskc-demolitions/v1/prod/latest.geojson` contains every currently exported mapped demolition record.
- `maps/compasskc-demolitions/v1/prod/by-year/{year}.geojson` contains year-filtered exports.
- Reporter preview and CMS embed copy pages are generated by the CompassKC service, not stored in this public data repo.

## Publishing Contract

- Publish only fields needed by reader-facing maps.
- Do not include owner/taxpayer fields, raw scrape payloads, private notes, credentials, or full parcel layers.
- Keep paths stable so CUE/WPS embeds can fetch the same URL after story publication.
- Write refreshed pipeline output to `testing/` first, audit it, then promote the same schema to `prod/`.
- Prefer GitHub Pages URLs such as `https://mcclatchyai.github.io/newsroom-data/maps/compasskc-demolitions/v1/prod/manifest.json`.
- Prefer `manifest.json`, `latest.geojson`, and scoped folders such as `by-year/`.
